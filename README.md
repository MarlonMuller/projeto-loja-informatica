# 🖥️ Projeto Loja de Informática

Aplicação web que simula uma loja de informática, permitindo visualizar produtos, adicionar ao carrinho e calcular o total da compra.  
Desenvolvida com **HTML, CSS e JavaScript**.

---

## 🔗 Acesse o projeto online

👉 [Visite a Loja de Informática](https://projeto-loja-informatica.vercel.app/index.html)

## 💡 Funcionalidades

- Exibição de catálogo de produtos de informática (nome, preço, imagem)  
- Adicionar e remover itens do carrinho  
- Cálculo automático do valor total da compra  
- Interface simples e intuitiva para simulação de compras  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura da aplicação  
- **CSS3** — estilização visual e responsividade  
- **JavaScript (ES6+)** — manipulação do DOM, lógica do carrinho e cálculo do total  

---

## 📂 Como usar localmente

1. Clone o repositório:
```bash
# Clone este repositório
git clone https://github.com/MarlonMuller/projeto-loja-informatica.git
```

2. Acesse a pasta do projeto:
```bash
cd projeto-loja-informatica
```
3. Abra o arquivo `index.html` no navegador.
